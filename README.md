# PCL 低版本安装包仓库

用于存放和分享个人收集、使用过的 PCL（Poor's Cool Launcher）低版本安装包。这个仓库的目标是为需要回退到旧版本、进行兼容性测试、或在特定环境下使用历史版本启动器的用户提供一个便捷的下载入口。

> 说明：本仓库仅用于存档和分享个人使用过的低版本 PCL 安装包，不代表官方维护，也不保证覆盖全部历史版本。

## 仓库简介

PCL 是一个广泛用于 Minecraft 相关社区的启动器/整合工具，早期版本在配置方式、启动逻辑、兼容性和界面表现上与新版本存在较大差异。很多玩家在使用高版本 PCL 时，可能会遇到新世界下载、旧配置兼容、启动异常、资源路径问题等情况，因此常常需要回退到低版本进行测试或继续使用。

本仓库的主要目的，是为这类场景提供历史版本安装包，便于快速下载、备用和恢复。

## 适用场景

- 需要使用较低版本 PCL 的用户
- 需要回退到旧版本进行兼容测试的用户
- 新版本 PCL 无法正常下载新的世界，需使用旧版进行恢复或测试的用户
- 想快速找到历史版本安装包的用户
- 想保留自己常用旧版启动器环境的用户

## 仓库特点

- 仅收录个人常用、测试过或留档的低版本安装包
- 适合快速下载和备用
- 便于查找旧版 PCL 以解决兼容性问题
- 不追求全量历史版本覆盖
- 面向“个人存档与共享需求”，而非官方维护项目

## 下载说明

1. 进入仓库的 Releases 页面或对应目录下载压缩包。
2. 下载后将压缩包解压到本地目录。
3. 确认解压后文件结构正常，重点检查是否包含启动器主体及配置文件。
4. 根据实际情况以管理员方式运行程序，必要时检查 `Setup.ini` 等配置。

## 常见使用步骤

### 1. 解压文件

将下载的压缩包解压到任意目录，建议不要放在系统盘根目录，以避免权限问题。

### 2. 检查配置文件

解压后，请重点检查以下文件中的配置是否正确：

- `./PCL/Setup.ini`

确认是否存在以下配置：

```ini
SystemSystemUpdate:3
```

如果没有该项，请手动添加。缺失该项可能导致启动器行为异常、配置未生效，或出现兼容问题。

### 3. 启动程序

根据实际环境，双击启动器或运行对应的可执行文件。若系统提示权限不足，建议以管理员身份运行。

## 常见问题

### Q：为什么没有我想要的版本？
A：因为本仓库仅上传本人所需、常用或留档的低版本安装包，不会囊括全部历史版本。

### Q：为什么启动后报错？
A：请先确认解压后是否已检查 `PCL/Setup.ini`，并确认是否缺少 `SystemSystemUpdate:3`。

### Q：高版本 PCL 不能下载新的世界，为什么要用低版本？
A：有时旧版本启动器在兼容性、配置方式、世界下载流程和启动逻辑上与新版本不同，部分用户在高版本遇到异常时，会回退到稳定的低版本进行测试或继续使用。

### Q：这个仓库是官方项目吗？
A：不是官方项目，主要用于个人整理、存档和分享。

### Q：我能贡献安装包吗？
A：欢迎提交 Issue 或在适当情况下交流分享。请注意本仓库的定位仍然是“个人维护的低版本档案仓库”。
