# pcl_launcher

这是一个用于存放低版本 PCL 安装包的仓库。本仓库只收录本人使用过的低版本安装包，目的在于方便快速下载与备用，不保证包含所有版本，也不提供全量版本合集。

> 说明：本仓库仅用于分享和存档个人使用的低版本 PCL 安装包，不代表官方维护，也不包含所有历史版本。

## 项目简介

PCL（Poor's Cool Launcher / Profile/Player launcher，常见于 Minecraft 相关社区）低版本安装包往往在兼容性、配置、启动逻辑等方面与高版本存在差异。为了方便在需要时快速回退使用，本仓库整理并发布了部分低版本安装包。

## 适用场景

- 需要使用较低版本 PCL 的用户
- 需要回退到旧版本进行兼容测试的用户
- 想快速找到历史版本安装包的使用者
- 想保留个人常用旧版环境的用户

## 下载说明

1. 进入仓库的 Releases 页面下载对应版本压缩包。
2. 下载后解压到本地目录。
3. 进入解压后的文件夹，确认目录结构正确。
4. 按需运行启动器或安装程序。

## 使用步骤

### 1. 解压文件

将下载的压缩包解压到任意目录，建议不要放在系统盘根目录，避免权限问题。

### 2. 检查配置文件

解压后，请检查以下文件中的配置是否正确：

- `./PCL/Setup.ini`

确认其中是否存在：

```ini
SystemSystemUpdate:3
```

如果没有，请手动添加该配置项。缺失该项可能会导致启动器行为异常或配置未正确生效。

### 3. 启动程序

根据你的实际环境，双击启动器或运行对应的可执行文件。若有权限提示，请以管理员身份运行。

## 注意事项

- 本仓库不保证涵盖所有版本。
- 由于不同版本可能依赖不同的运行环境，请自行确认系统兼容性。

## 常见问题

### Q：为什么没有我想要的版本？
A：因为本仓库仅上传本人所需和常用的低版本安装包，不会囊括全部历史版本。

A：请先确认解压后是否已检查 `PCL/Setup.ini`，并确认是否缺少 `SystemSystemUpdate:3`。
